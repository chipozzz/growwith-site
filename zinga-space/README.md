# ZINGA spAce サイト リニューアル — ワイヤーフレーム

現行サイト（https://zinga-space.com/）を手書きメモの構成で作り直すためのワイヤーフレームです。
**新規プロジェクト**として `zinga-space/` に独立させています。リポジトリ直下の既存ファイル（Grow with 株式会社サイト）や、香り診断ツールとは別物です。

- 色・写真・文章はすべて仮（グレーの箱・線＝あとで入るもの）
- 青い点線ラベル＝メモの番号との対応、オレンジ＝要確認
- ブラウザで `index.html` を開けばそのまま全ページを行き来できます（ビルド不要）

## サイト全体のルール（メモ「全体」より）

- 香り診断はメニューの中にアクセント程度に入れる（黒いピル型ボタン・外部リンク）
- ページ遷移時の「spAce」表示（ローディング演出）は入れない
- メニューに「トップ」は入れない（ロゴでトップへ戻る）
- メニューの「事業内容」「ブランドコンセプト」には下層ページをサブメニューで表示
- 公式LINEの右下固定ボタン → メモで取り消し線のため入れていない

## 要確認ポイント

1. 2つのブランド（SpAce・Op.parfum）がそれぞれ何を扱うか、サービスページとつなぐか

※ 問い合わせCTA（各ページ下の帯）は全ページ共通で表示
